# NOCTARIA updates

Latest-version info for NOCTARIA's Unity tools.
The tools read the JSON file here (at most once a day) to show a small "new version available" notice in the Unity Editor.

- The tools only **download** this file. They send nothing about you, your project or your PC.
- You can turn the check off in each tool's menu (e.g. `Tools/NOCTARIA/ScenePeek`).

| Tool | File |
|---|---|
| ScenePeek | [`scenepeek.json`](scenepeek.json) |
